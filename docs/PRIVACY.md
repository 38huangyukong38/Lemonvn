# LemonVN V0.1 数据与网络说明（审查稿）

项目主页：https://github.com/38huangyukong38/Lemonvn 。本说明依据当前实现编写，并在M6-B2-A源码准备时复核；没有新增账户、遥测或云端服务。正式公开前仍需随最终二进制与第三方政策再次核对。

## 本地数据

收藏、评分、标签、备注和逐集记录保存在LemonVN专属LiteDB；封面、设置、备份、缓存和日志使用同一专属根目录。非打包默认在`%LocalAppData%/LemonVN`，打包模式使用经身份校验的独立包LocalFolder。开发测试可显式指定独立根，不读取PotatoVN收藏或配置。

删除条目会进入回收站；恢复副本和历史封面保留。永久删除要双重确认并先生成备份，当前没有自动清理历史封面的功能。ZIP备份包含收藏/回收站、个人记录及引用封面，不含设置、日志、无关缓存或凭证；分享备份会同时分享其中的个人内容。

## 主动网络操作

- Bangumi：主动搜索发送检索词，预览/刷新发送作品ID，封面下载访问受限官方图片地址；不登录、不读写用户账户收藏。
- 截图识别：用户选择图片后仅本地校验/预览；确认后向Trace.moe发送内存JPEG副本。
- 角色识别：同样确认后向AnimeTrace发送JPEG，文件名固定`upload.jpg`。不接入其Agent或角色图片服务。
- 识别副本最长边1600、去元数据，不发送原文件名/路径、收藏或观看记录，不默认持久化原图或识别结果。匹配帧仅在主动点击时下载至内存。取消停止本地请求，已经发出的内容无法撤回。

服务会接收到请求所需的网络信息，包括公网IP；处理方式和限制以[授权风险清单所列官方政策](API_AND_LICENSE_RISKS.md)为准。LemonVN没有承诺替第三方撤回已发送图片，也不保证识别正确。

## 日志与凭证

本地日志按日滚动、保留最多7个文件，不自动发给开发者。一般存储诊断可能包含文件操作路径；网络/识番错误使用受限类别，不记录原始图片、响应正文、敏感请求头或原图私密路径。主动分享日志前可检查其中内容。

当前没有Token输入、保存或账户授权界面；收藏数据库和ZIP不保存服务凭证。系统代理和TLS信任由Windows网络环境提供，应用不关闭证书校验或记录代理凭证。

程序打开页面、选择图片或启动应用不会自动上传收藏/图片；公开API只由用户主动操作触发。断网时本地管理、进度及备份继续可用。发布前需将本说明与最终二进制、服务政策及帮助入口再次核对。
